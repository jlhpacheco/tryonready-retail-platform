# Hackathon Scope

TryOnReady is being prepared for the YouCam API Skin AI & Apparel VTO Hackathon. The primary API category is Apparel Virtual Try-On.

The official Devpost page currently lists the submission deadline as **August 17, 2026 at 11:45 AM EDT**.

## Approved first phase

The first phase is limited to a safe, buildable scaffold:

- Next.js, React, TypeScript, responsive and accessible web shell
- PWA manifest baseline
- public landing page and placeholder workflow navigation
- ASP.NET Core 10 API, class libraries, worker, OpenAPI, and health checks
- neutral server-side adapter contracts for a future YouCam integration
- synthetic fixtures and lean domain concepts
- unit, integration, lint, type-check, and build verification

## Explicitly out of scope

- live YouCam requests or a claim that integration is complete
- production deployment or public repository visibility
- production PostgreSQL connections or migrations
- native App Store packages
- real retailer/customer records or customer photographs
- physical fit, size accuracy, medical, or diagnostic claims
- complete product, analytics, moderation, billing, or identity systems

Stop after the first scaffold and verification. A reviewed follow-up task is required before implementing live Apparel VTO calls.

## Judging and later submission

The official judging criteria cover technological implementation, design, potential impact, and quality of the idea. A competitive submission must eventually demonstrate a real YouCam API integration as part of a coherent product with clear retail or consumer value.

The final hackathon submission will also require:

- a functional source repository (public with relevant licensing, or private and shared with the judging contact)
- a clear feature and value description
- screenshots
- a public one-to-three-minute end-to-end demo video that identifies the YouCam API used

These deliverables are not part of the first scaffold.
