# TryOnReady Guide for Small Boutiques

This guide explains the current TryOnReady image-readiness check and the planned complete experience in simple language.

## What works today

The current website has a working first step. You can:

1. Open the public TryOnReady home page.
2. Read how the service is intended to help small boutiques.
3. Open **Product Readiness**, enter garment details, and choose a JPEG, PNG, or WebP image.
4. Check whether the image type, size, and dimensions meet the basic requirements.
5. Read a clear result explaining what to fix.
6. Open the Boutique Application, Admin Review, and Consumer Try-On preview pages.
7. Review the privacy promise explaining what a boutique may and may not see.

The photograph stays in the browser during this check. TryOnReady sends only the file name, media type, file size, and image dimensions to the local API. The site does not yet save applications, upload photographs, call YouCam, approve products, or publish customer pages.

## How a boutique owner will use the finished workflow

### 1. Open TryOnReady

Open the website on a phone, tablet, laptop, or desktop computer.

### 2. Apply for the boutique

Choose **Boutique Application**.

Enter basic information about the shop and submit the application. TryOnReady will review it before products can be published.

### 3. Add a garment

After the boutique is approved, choose **Product Readiness**.

Enter a simple product name, product number, and garment category.

### 4. Take or upload a garment photo

Use a clear, well-lit photograph of the garment. Make sure the complete garment is visible and the background is not distracting.

Use only photographs the boutique owns or has permission to use.

### 5. Follow the readiness guidance

TryOnReady checks basic image details before using a paid API unit.

If the photograph is too small, unsupported, or unclear, follow the instructions and try again.

### 6. Submit for virtual try-on validation

When the garment is ready, submit it for processing.

TryOnReady will send the required images to YouCam from the secure server. The boutique will never handle or see the API key.

### 7. Wait for processing

The product status will show whether processing is waiting, running, successful, or unsuccessful.

Do not submit the same garment repeatedly while a job is already running.

### 8. Wait for administrative review

A TryOnReady administrator reviews the product and processing result.

The administrator may approve it, decline it, or ask the boutique to improve the garment information or photograph.

### 9. Publish the customer page

After approval, publish the customer try-on page.

Share the page link from the boutique website, product page, social media, QR code, or customer message.

### 10. View simple activity totals

The boutique may eventually see:

- product-page visits
- try-on counts
- successful and unsuccessful processing totals
- outbound boutique-link clicks
- API-unit use

The boutique must never see:

- customer source photographs
- generated customer photographs
- private customer attributes
- customer image-analysis details

## What TryOnReady does not promise

TryOnReady helps a customer visualize a garment. It does not promise physical fit, correct sizing, medical results, or diagnostic conclusions.

## If something does not work

1. Read the message shown on the page.
2. Check that the garment photograph meets the stated requirements.
3. Do not keep resubmitting a paid request.
4. Contact TryOnReady support with the product number and time of the problem.
5. Never send a customer photograph, API key, password, or payment information in a support message.
